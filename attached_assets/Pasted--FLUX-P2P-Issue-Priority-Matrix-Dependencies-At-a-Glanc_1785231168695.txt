## ⚠️ Red Flags During Implementation

### Stop and Review If:

1. **STUN/TURN [1] taking > 1 week**
   - Check: Are you over-engineering?
   - Solution: MVP first (2 STUN + 1 TURN), add more later

2. **Signaling Server [2] not connecting to P2P Engine [1]**
   - Problem: Likely integration issue
   - Solution: Daily sync between teams, shared test harness

3. **Room Lifecycle [3] deleting active rooms**
   - Problem: Timeout logic too aggressive
   - Solution: Increase inactivity threshold, add warnings

4. **Error Handling [4] silencing real errors**
   - Problem: Over-catching exceptions
   - Solution: Log all errors, only silence user-facing messages

5. **Validation [5] rejecting valid input**
   - Problem: Regex too strict or data format assumption wrong
   - Solution: Test with real user data, add debugging output

6. **File Transfers [6] failing on 100 MB files**
   - Problem: Chunk size or memory issue
   - Solution: Reduce chunk size, test with larger increments
